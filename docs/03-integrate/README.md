# Stage 03 — INTEGRATE

This directory will contain API contracts and integration specifications for Nanobot's external integrations:

- **LLM Provider integrations** (13+ providers via LiteLLM)
- **Channel integrations** (9 platforms: Telegram, Discord, Slack, WhatsApp, Feishu, DingTalk, Email, QQ, Mochat)
- **MCP server integrations** (Model Context Protocol for external tools)

See [ADR-002](../02-design/ADR-002-litellm-multi-provider.md) and [ADR-003](../02-design/ADR-003-message-bus-pattern.md) for architecture decisions.
